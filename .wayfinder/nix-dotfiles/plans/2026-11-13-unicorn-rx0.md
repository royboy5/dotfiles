# Nix Port, Plan 3: `unicorn-rx0` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `unicorn-rx0` (Dell XPS 13 9370, fresh NixOS) as the NixOS host. `./bootstrap` runs `nixos-rebuild switch` for `nixosConfigurations.unicorn-rx0`, whose system layer lives in `nix/nixos/`, with home-manager as a NixOS module applying the same user layer as the other hosts. Then `nix` merges to `master`.

**Architecture:** `nix/flake.nix` gains a `nixos-hardware` input and `nixosConfigurations.unicorn-rx0`, built from `nix/nixos/default.nix` (shared system layer), `nix/nixos/desktop.nix` (GUI system layer), `nix/nixos/unicorn-rx0.nix` (this machine: hardware, power, boot, `stateVersion`) and home-manager's NixOS module. Home-manager imports `nix/home` plus `nix/hosts/unicorn-rx0.nix`, which picks a new `nix/home/targets/nixos.nix` (the NixOS `nrs`/`ngc`) and `nix/home/gui.nix`. Bash gains `lib/hosts/unicorn-rx0.sh`.

**Tech Stack:** Nix flakes, NixOS (unstable), home-manager NixOS module, nixos-hardware, bash, bats.

**Spec:** `.wayfinder/nix-dotfiles/map.md` and its tickets. This plan uses tickets 03 (flake layout, as amended), 04 (package ownership, including the 2026-11-12 Bitwarden amendment), 05 (bootstrap flow: the NixOS row, as amended), 07 (zsh), 08 (nix-ld), 09 (`unicorn-rx0`'s system layer), 12 (fonts), 13 (Hyprland), 14 (cutover and merge) and 15 (README). Plans 1 and 2 built everything this plan extends.

**Later plans:** `qant-00` (Bazzite), which clones `master`.

## Review Focus

1. **Fresh NixOS without git.** The installer doesn't ship git, and bootstrap's first check runs git. Expect: bootstrap stops with "git isn't installed" and the `nix-shell -p git` instruction, not a raw "command not found". Covered in Task 3.
2. **First switch with flakes not yet enabled.** A fresh NixOS `nix.conf` has no flakes. Expect: `nix flake lock` uses `NIX_FLAGS`, and `nixos-rebuild` gets `--option experimental-features "nix-command flakes"` on every run. Covered in Task 3.
3. **`/etc/nix/nix.conf` is read-only on NixOS** (a store link). Expect: the NixOS path never runs `ensure_nix`, `ensure_flakes`, `ensure_login_shell` or the GPU setup. Covered in Task 3.
4. **The hardware file missing, or present but untracked.** Expect: bootstrap stops before any rebuild and prints `nixos-generate-config --show-hardware-config > nix/nixos/hardware/unicorn-rx0.nix` (missing), or the existing untracked-files error (untracked); a build without it fails on the assertion's message. Covered in Tasks 2 and 3.
5. **Two power daemons, or the wrong portal per session.** Expect: exactly power-profiles-daemon (TLP and system76-power off), checked by eval in Task 2; the portal picked per session (COSMIC vs Hyprland) is checked at acceptance in Task 5 (screen sharing or a file picker in each session).
